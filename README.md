# Superstore Sales and Profit Analysis Dashboard

A multi-page Power BI dashboard that explores sales and profitability across regions, states, product categories, and customer segments.

## Tools Used
Power BI, Microsoft Excel, MySQL

## Dashboard Pages
- Sales and profit by region and state
- Customer segment performance
- Monthly sales and profit trends
- Shipping methods and average shipping time
- Product subcategory performance

## Features
Slicers, drill-through views, KPI cards, and a decomposition tree for exploring what drives sales and profit.
